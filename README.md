# presentation-design-lab

## Overview
A personal research project exploring presentation
design principles and AI-assisted slide generation.

## Objectives
- Collect high-quality presentation references.
- Analyze slide composition and visual hierarchy.
- Extract reusable presentation design principles.
- Apply the principles to AI presentation workflows.
- Evaluate the quality of generated presentations.
